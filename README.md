# BuyAgain

Smart shopping lists for food and household things. Check items with one hand, keep the total on screen, and make the next list from the last trip.

Package: `com.BuyAgainMNG.BuyAgain`

Remote config: [N303.json](https://api2.blwsmartware.net/N303.json) — `disable=1` hides Google Play Billing popups only. Shop stays open for coin unlocks.

| Product ID | Type |
| --- | --- |
| `ba_pack_1` … `ba_pack_10` | Consumable coins |
| `ba_remove_ads` | Non-consumable |
| `ba_pro` | Non-consumable, more than 8 lists |

Lists and usual items stay on the device. No account.
